description: Open the website so I can see it
---

Show the user the site.

1. Start the dev server using `preview_start` with the `Room Within`
   configuration. If it's already running, reuse it.
2. Navigate to the page the user asked about. If they didn't name one, open the
   home page.
3. Say in one line which page is showing, and invite them to tell you what
   they'd like changed.

If the server fails to start, check the logs, fix the problem yourself, and try
again. Don't show the user the error.
